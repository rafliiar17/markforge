# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within MarkForge, please submit a report privately by sending an email to `rafli@example.com` or creating a GitHub Private Vulnerability Advisory.

Please include:
- A detailed description of the vulnerability.
- Steps or a minimal Markdown snippet to reproduce the issue.
- Potential impact and affected components (CLI, MCP, Web, Core).

We commit to acknowledging your report within 48 hours and delivering patches in a timely manner.
