## [1.0.0] - 2026-09-07

### Features
- **Core Engine**: High-fidelity Markdown to OpenXML DOCX & PDF conversion with 1:1 layout parity.
- **Templates**: Built-in styling presets for `ats-classic`, `modern-accent`, `tech-spec`, `academic`, and `executive`.
- **ATS Auditor**: AST-based ATS scoring system evaluating action verbs, quantifiable metrics, and structure compliance.
- **Developer CLI**: Full command-line tool with `build`, `watch`, `analyze`, `templates`, and `doctor` commands.
- **MCP Server**: Model Context Protocol integration providing native document compilation and analysis tools for Claude, Cursor, and Antigravity.
- **Web Studio**: Next.js 15 App Router studio with split-screen editor, simulated A4 canvas preview, and official shadcn/ui components.
